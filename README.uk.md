# HomeLink

[![CI](https://github.com/Alexsik76/homelink-tray/actions/workflows/ci.yml/badge.svg)](https://github.com/Alexsik76/homelink-tray/actions/workflows/ci.yml) [![Release](https://img.shields.io/github/v/release/Alexsik76/homelink-tray)](https://github.com/Alexsik76/homelink-tray/releases/latest)

[English](README.md)

Програма для системного лотка Windows, яка відкриває доступ до домашнього ПК: підіймає тунель WireGuard, доручає маршрутизатору MikroTik надіслати
Wake-on-LAN і показує стан тунелю та ПК у значку.

## Версія 1.0 на Rust (у розробці)

HomeLink переписується на Rust з інтерфейсом Slint; код — у теці `rust/` гілки `main`.
Його ще не випущено; він вийде як версія 1.0.0. Випущену версію 0.3.0 на Python
перенесено до архіву [`legacy/python`](legacy/python/README.uk.md).

Що змінюється:

- **Кілька ПК і тунелів.** Панель біля лотка показує тунелі ліворуч, а навпроти кожного —
  ПК за ним; ПК без тунелю йдуть останніми. Кожен елемент — назва й позначка стану
  (зелена: працює, жовта: у процесі, синя: вимкнено, сіра рамка: невідомо, червона: лише
  збій). Лівий клік відкриває дії, правий — вікно відомостей. Сон і вимкнення потребують
  другого натискання.
- **Способи пробудження для кожного ПК:** магічний пакет на будь-яку адресу,
  вузол-посередник через SSH (RouterOS, `etherwake` або `wakeonlan`) чи власна команда.
- **Жодних секретів і жодного клієнта HTTP.** До маршрутизаторів і ПК програма звертається
  системним клієнтом OpenSSH за ключем; REST маршрутизатора більше не використовується.
  Програма не зберігає паролів, не надсилає телеметрії й з'єднується лише з вузлами з
  налаштувань. CI не пропускає збірку, у яку потрапила бібліотека клієнта HTTP чи TLS.
- **Налаштування в `config.toml`** змінюються на місці, тож коментарі зберігаються; є вікно
  налаштувань і майстер додавання ПК із п'яти кроків (створення ключа, довіра ключу вузла
  лише після підтвердження відбитка, команди для налаштування посередника).
- Світла й темна теми, англійська та українська мови, сповіщення в лотку, маніфест із
  правами адміністратора.

Стан на 15.11.2026: панель і справжній режим працюють на Windows 10 LTSC (тунель
піднімається командою програми). Ще не перевірено на справжньому комп'ютері: майстер,
сповіщення в лотку, створення ключа й довіра ключу вузла, пробудження, сон, вимкнення й
RDP у справжньому режимі, команди для RouterOS. Довідку ще не написано.

**Як спробувати.** Відкрийте останній
[запуск CI гілки `main`](https://github.com/Alexsik76/homelink-tray/actions/workflows/ci.yml?query=branch%3Amain)
і завантажте артефакт `HomeLink-rust-demo`. `HomeLink.exe --demo --lang uk` показує панель
з імітованими ПК і тунелями (`--theme light|dark` вибирає тему). Без `--demo` програма діє
по-справжньому: під час першого запуску створює `config.toml` поруч із виконуваним файлом
за шаблоном і завершується; заповніть його й запустіть знову (`--config <шлях>` вказує
інший файл). Програма запитує права адміністратора.

**Збирання** (стабільний Rust; застосунок працює на Windows, ядро й тести — також на
Linux):

```
cd rust
cargo test --workspace --all-features
cargo build -p homelink --release --features demo
```

Проєктні документи: [архітектура](docs/rust-architecture.md),
[інтерфейс](docs/design/ui-handoff.md)
і його [темна тема](docs/design/ui-handoff-dark.md)
(англійською).
